# ⚖️ Multi-Agent Debate & Decision System

The Multi-Agent Debate & Decision System is an **Agentic AI application** that uses multiple AI agents to analyze a topic from different perspectives and generate a balanced final decision.

The system consists of specialized agents with different roles. One agent focuses on the **benefits and opportunities**, while another analyzes **risks and limitations**. A moderator agent evaluates both viewpoints and generates the final recommendation.

The application uses **CrewAI** to coordinate the agents and **Groq with LLaMA** for generating responses. A simple **Streamlit interface** allows users to enter a topic and view the complete debate and final decision.

**Tech Stack:** Python, CrewAI, Agentic AI, Groq API, LLaMA, Streamlit
